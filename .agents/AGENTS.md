# Project-Specific Constraints

- **Mobile First Responsive Design**: Every new feature, UI component, or page update added to this project must be fully responsive, mobile-optimized, and aesthetically polished on smaller screens. Always verify mobile layouts, element paddings, font sizes, and grids (e.g. using 2-column structures or compact card templates on mobile screen sizes).
- **Arabic Localisation Support**: Maintain Arabic language direction (`dir="rtl"`) and the personal brand typography style across both public pages and the admin dashboard.
